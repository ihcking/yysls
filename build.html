第一章：核心理念与基础公约

我们的初心
轻量共筑，自然生长

百业诞生于一个简单的愿望：创建一个不内卷、有温度、共同成长的游戏家园。我们拒绝复杂的官僚体系，坚信最好的协作源于自发的热情与清晰的共识。

一、我们的初心：轻量共筑，自然生长

三条根基性原则：

  1. 现实生活优先原则：游戏是生活的点缀。任何时候，学业、工作、健康、家庭都排在公会活动之前。我们鼓励"忙时潜水，闲时归来"，绝不因游戏影响现实生活的平衡。
  2. 贡献多元认可原则：贡献不仅是组织活动或输出攻略。一次暖心的欢迎、一个有趣的表情包、一次耐心的解答、一份整理的记录，甚至只是在聊天中营造积极氛围，都是同等珍贵的贡献。
  3. 体系服务人文原则：所有规则、职位、流程都是工具，唯一目的是让成员更舒心地玩耍与协作。当工具带来负担时，我们有权共同修改它。体系应为人服务，而非束缚。

第二章：六大职能小组详细职责与协作接口

六大职能小组构成公会的核心架构，每个小组都有明确的职责和协作接口，确保公会运营高效且充满活力。

活动组 🎯
公会活力的引擎

核心职责清单：

  • 常规活动：每周至少组织1次线上集体活动（如趣味PVP、竞速赛、探索活动等）
  • 节日/版本活动：在游戏节日或新版本更新时，策划特别庆祝活动，提升节日氛围
  • 活动支持：为其他小组的活动提供"趣味化"建议，让严肃内容变得生动有趣
  • 反馈收集：每次活动后收集反馈，持续优化活动体验和参与度
  • 活动预告：提前3-5天发布活动预告，确保成员有充足时间安排

协作接口：

  • 对指挥组："我们想办个趣味PVP赛，能帮我们设计个简单规则并主持吗？"
  • 对文艺组："下周活动需要一位'御用摄影师'记录精彩瞬间，求支援！"
  • 对休闲组："新活动想加入破冰环节，能帮忙设计些互动游戏吗？"

第三章：七阶成长路径详细说明

清晰的成长路径让每位成员都能找到自己的位置，每个阶段都有明确的能力要求和晋升标准，但最重要的是在适合自己的位置发光发热。

成长阶梯总览

社众 → 先知 → 大师 → 执事 → 香主 → 副社 → 副社主（轮值） → 长老（邀请）

每个阶段都有明确的能力要求和晋升标准，但最重要的是在适合自己的位置发光发热。在任何阶段停留都是被鼓励和认可的。

每一阶都是责任形态的转变，是自然生长，而非竞赛。前三个月重点在前三阶，后续阶段随公会发展自然开启。

—— 百业共筑核心理念

第四章：详细操作机制

清晰的操作机制确保百业运营高效透明，所有流程都旨在简化操作、降低门槛、提升体验。

一、活跃度与清退机制

  1. 活跃度要求：
    • 预备组员：正式成员需保持周活跃≥3000，离线超过3天可能面临清退。
    • 先知及以上：先知及以上需≥4000，离线超过3天可能面临清退。
    • 执事及以上：需保持高活跃度参与百业管理
  2. 清退机制：
    • 周活跃度低于3000且超过3天可能面临清退
    • 离线超过3天且未请假者，可能被清退
    • 多次违反公会公约且警告无效者，经管理会议讨论后清退
  3. 请假制度：
    • 短期请假（1-7天）：在群内@香主或管理说明即可
    • 中期请假（8-30天）：需填写请假表，由副社审批
    • 长期请假（30天以上）：转入休眠状态，保留回归资格

二、晋升申请标准化流程

  1. 步骤一：资格自查：对照晋升条件，确保满足活跃度、造诣等基本要求。
  2. 步骤二：填写申请表：
    • 进群申请：填写百业登记表
    • 执事申请：填写百业共筑表
  3. 步骤三：提交申请：在"百业群"发布固定格式消息，同时将申请表发送给直属上级及长老会成员备案。
  4. 步骤四：评审与考察（7日内完成）：
    • 大师及以下：由香主主导，征询组内同事意见后批准
    • 执事：香主评审+1位其他组香主+1位副社书面同意
    • 香主及以上：管理会议讨论+同行评议+成员投票
  5. 步骤五：晋升仪式：在每周公会活动前，发布全员通知。

三、日常活动组织流程

  1. 活动策划：活动组提前一周策划活动方案，提交管理群审议。
  2. 活动预告：提前3-5天发布活动预告，包括时间、内容、要求等。
  3. 活动执行：
    • 每晚20:00固定百业派对
    • 每周至少1次副本和百业战（造诣≥3.5组织）
    • 每月1次大型主题活动
  4. 活动记录：文艺组负责活动影像记录，技术组负责数据统计。
  5. 反馈收集：活动后24小时内收集参与者反馈，用于优化后续活动。

四、争议解决流程

  1. 第一步：直接沟通：鼓励双方私下直接、冷静地沟通。
  2. 第二步：调解介入：邀请双方都信任的第三位成员进行调解。
  3. 第三步：小组评议：提交至当事小组全体或公会管理会议进行评议。
  4. 第四步：长老裁决：仅在最严重且无法达成共识的情况下，由长老会作出最终裁决。

第五章：给不同成员的行动指南

每个成员都是独特的，新芽公会尊重并支持每个人的游戏方式和参与程度。以下指南帮助您找到最适合自己的参与方式。

高活跃玩家

核心要求：周活跃≥4000，造诣≥3.5，积极参与各项活动

  • 优先填写百业共筑表，争取先知及以上职位
  • 积极参与每晚20:00的百业派对
  • 主动承担副本组织和百业战协助工作
  • 协助新人快速提升活跃度和游戏理解
  • 保持良好出勤率，离线超过3天需提前请假
  • 参与百业交流，为百业发展建言献策

稳定支持者

核心要求：周活跃≥3000，遵守百业公约，稳定参与活动

  • 确保每周活跃度达标，避免被降级或清退
  • 优先参加重要活动（副本、百业战等）
  • 在群聊中多给予他人正向反馈和鼓励
  • 提前告知自己的时间安排，便于团队规划
  • 填写百业登记表，完善个人资料

管理型玩家

核心要求：已任职执事及以上，积极参与百业管理

  • 定期查看成员活跃度数据，及时沟通低活跃成员
  • 组织策划各类活动，确保每周活动丰富多样
  • 培养新人，为公会储备管理人才
  • 优化管理流程，提升百业运营效率
  • 处理成员争议，维护公会和谐氛围
  • 定期提交管理报告，总结工作成果

休闲玩家

核心要求：享受游戏，保持基本活跃，遵守公约

  • 优先享受游戏乐趣，不必过度追求活跃度
  • 选择性参加感兴趣的活动，不必有压力
  • 在聊天中多分享游戏中的小确幸和美好瞬间
  • 当你感到疲惫时，坦然休息，不必有负担
  • 保持基本活跃（≥3000），避免被清退
  • 你的快乐会感染所有人，这就是最大的贡献

新人玩家

核心要求：快速提升，学习成长，融入集体

  • 第一时间填写百业登记表
  • 熟悉并遵守公会基础公约
  • 积极提升活跃度，争取尽快达到3000+
  • 多向老玩家请教，快速提升游戏理解
  • 参加新手引导活动，熟悉百业运作
  • 寻找一位"导师"，定期进行复盘和交流
  • 大胆发言提问，百业鼓励新人积极交流

时间不固定玩家

核心要求：合理安排，高效参与，及时沟通

  • 明确告知自己的游戏节奏，让团队有所预期
  • 在活跃期集中贡献，在潜水期安心休息
  • 关注公告和活动日历，选择重要活动参与
  • 离线超过3天必须提前请假
  • 回归时主动了解期间的变化，快速重新融入
  • 担任"特邀嘉宾"角色，在关键时刻提供独特价值

第六章：常见问题解答（FAQ）

以下是我们收集到的最常见问题，希望能帮助您更好地理解公会的运作方式和文化理念。

周活跃度是怎么计算的？

A：周活跃度基于游戏内的活跃系统计算，包括百业活动任务完成、副本参与、活动参与等。具体数值可在游戏内查看。公会每周日会统计成员活跃数据。

如果达不到活跃度要求会怎样？

A：周活跃低于3000且或者离线三天可能会被清退；连续不达标可能影响晋升或面临清退。我们理解现实忙碌，请提前请假说明情况。

造诣3.5是什么意思？怎么达到？

A：造诣是游戏内的角色实力指标，通过装备提升、技能升级、天赋解锁等途径提高。3.5是参与公会核心活动的基本要求。技术组会提供提升攻略，也可请教老玩家。

百业登记表和百业共筑申请表有什么区别？

A：百业登记表是入群基本资料登记；百业共筑表是晋升执事及以上职位的详细申请，包含个人规划、管理理念等更深层次内容。

每晚20:00的百业派对必须参加吗？

A：不是强制要求，但强烈建议参加。这是公会成员日常交流互动的重要平台，也是提升活跃度的好机会。如果无法参加，不影响基本会员资格。

如果现实突然忙碌，我应该怎么处理百业事务？

A：请立即使用请假制度。短期请假在群内说明；中期填写请假表；长期可申请休眠。现实永远优先！我们鼓励"忙时潜水，闲时归来"。

百业如何处理成员间的个人矛盾？

A：我们鼓励成员首先尝试私下解决。如果无法解决，可以申请调解。对于严重且反复的冲突，可能会建议双方暂时减少直接接触。百业不会偏袒任何一方，只关注如何维护健康的社区环境。

这套体系会不会经常变动，让人无所适从？

A：大框架保持稳定，细节持续优化。核心原则和基础公约基本不变，操作流程会根据实践反馈每季度微调。所有变动都会提前公示并收集意见，重大调整需要成员投票通过。
